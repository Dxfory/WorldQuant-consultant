# Pixel Intact 微信小程序（完整版）

这是给手机用的独立完整版，包含电脑工作室的全部规则：原图完整、无损切图、清晰度、拼回、超大图自动分块、说明与隐私页。

手机上没有 Python / FSRCNN。超分是本地画布放大 + 清晰/锐化。更大画质请继续用电脑 `pixel-intact studio`。

## 该下载哪个开发者工具

打开 [微信开发者工具下载页](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)：

**只下载最上面的「稳定版 Stable Build」**，Windows 点 **Windows 64**。

不要下：预发布版 RC、开发版 Nightly、旧版 NWJS。那些给微信内部测新内核用，日常开发和上线用稳定版。

当前推荐版本号会变，以页面上带绿色「推荐」的那一行为准。

## 用微信开发者工具打开

1. 安装稳定版后，选择「导入项目」
2. 目录选：`pixel-intact/miniprogram`（不要选整个仓库根目录）
3. AppID 可先用「测试号」，或填自己的小程序 AppID
4. 不使用云服务，直接编译
5. 本仓库默认 `appid` 是 `touristappid`，只能在模拟器里看。要在手机预览，换成你的 AppID 或测试号

## 四个页

- **首页**：产品说明 + 选原图
- **暗房**：切图（九宫格 / 行列 / 像素块）和清晰度；超大图自动先切再逐块提高
- **拼回**：按文件名或选择顺序拼回，并检查空隙
- **说明**：全部规则、手机上限、电脑工作室、审核要点；内含隐私保护指引

## 使用

1. 点「选一张原图」，相册里选图（`sizeType: original`，不走压缩图）
2. 切图：九宫格 / 四宫格 / 16 宫 / 自己填行列，或按像素块
3. 可勾选「先提高清晰度再切」。整张超限时会自动先切再提高每一块
4. 点「处理」，再保存当前图、单块，或全部切块到相册
5. 「拼回」页把切块拼回去。相册常常不保留 `r00_c00` 文件名，请按选择顺序

## 手机上限

- 边长 4096px，或约 1200 万像素
- 例如 9505×13692 的线稿：不能一次 2× 整张输出；处理时会自动加密网格，丢弃像素仍为 0
- 拼回后若仍超限，请到电脑工作室拼

## 上线前你要做的

- 在微信公众平台注册小程序，拿到 AppID
- 把 `project.config.json` 里的 `appid` 改成你的
- 类目建议选「工具 > 图片处理」
- 介绍文案见 `介绍文案.md`
- 隐私协议可用小程序内「说明 → 隐私保护指引」，并在后台声明：图片只在手机本地处理，不上传服务器
